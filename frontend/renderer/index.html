字节序：同一寄存器内部两个字节是否交换；字序：多个寄存器之间是否交换。 默认都是 BE（大端，Modbus 标准）。float32/float64 按 IEEE754 解析。 32/64 位类型会占用 2/4 个寄存器，所以"寄存器个数"需为类型宽度的整数倍。
落盘阈值：电压、电流这类变化慢的数据，设个死区（如电压 0.5、电流 0.1）， 值没动就不写文件，可把本地写入量降 90% 以上；0 = 每轮都存。
上报别名：填中文名（如「电压」），MQTT 上报的 name 字段用它， id 字段仍用物理标识符；留空则 name 等于 id。

添加寄存器

MQTT 上报里 name 字段显示的中文名；id 字段仍用上面的物理标识符 从"寄存器地址"起连续读几个；16 位填 1，32 位填 2，64 位填 4 值变化超过该值才写入本地文件，0 = 每轮都存。 电压、电流这类变化慢的数据设个死区（如 0.5 / 0.1）可大幅减少写入量， 不影响实时值和 MQTT 上报
字节序 / 字序 怎么选
字节序：同一个寄存器内部，高低两个字节谁在前。
读到 0x01 0xF4 → BE 当成 500，LE 当成 61441
字序：跨多个寄存器时，寄存器之间谁在前（只影响 32/64 位类型）。
读到 0x00 0x01 | 0x00 0x00 → BE 当成 65536，LE 当成 1
16 位类型（int16/uint16）只占 1 个寄存器，字序不起作用。
绝大多数设备两个都选 BE；只有读数明显离谱（差 256 倍 / 字节对不上）时才试 LE。
